# Molecular Graph Generation with GNN-VAE

A deep learning project for **molecular graph generation using a Graph Neural Network-based Variational Autoencoder (GNN-VAE)**, implemented with **PyTorch** and **RDKit**.

The project explores how molecular structures can be represented as graphs, learned in a latent space, and reconstructed or generated by a neural network. The workflow covers the process from **data exploration and molecular preprocessing to model training, graph reconstruction, and molecule generation**.

The current version focuses on the generative model itself. **Reinforcement Learning for molecular property optimization was not implemented** and is left as a possible extension.

---

## Project Overview

A molecule is naturally represented as a graph:

```text
Atom  → Node
Bond  → Edge
```

Instead of treating a molecule only as a SMILES string, this project converts molecular structures into graph-based tensors and learns their underlying patterns with a GNN-VAE.

The main pipeline is:

```text
ZINC250k
    │
    ▼
SMILES
    │
    ▼
Data Exploration & Preprocessing
    │
    ▼
Molecular Graph
    │
    ▼
GNN Encoder
    │
    ▼
Latent Representation
    │
    ▼
Graph Decoder
    │
    ├── Node Features
    ├── Edge Features
    ├── Adjacency
    └── Global Features
            │
            ▼
    Generated Molecular Graph
            │
            ▼
          RDKit
            │
            ▼
 Validation & Visualization
```

## Dataset

The project uses **ZINC250k**, a commonly used benchmark for molecular generation.

The dataset contains drug-like molecular structures represented as SMILES strings, together with molecular information used for analysis and evaluation.

For this project, the molecular data includes:

* SMILES
* `LogP`
* `QED`
* `SAS`

The molecules are converted from SMILES into graph representations using **RDKit**.

---

## Molecular Graph Representation

Each molecule is represented using a fixed maximum graph size of:

```text
max_atoms = 50
```

The main tensors used by the model are:

| Component        | Shape            |
| ---------------- | ---------------- |
| Node features    | `[B, 50, 10]`    |
| Edge features    | `[B, 50, 50, 6]` |
| Adjacency matrix | `[B, 50, 50]`    |
| Atom mask        | `[B, 50]`        |
| Global features  | `[B, 3]`         |

where `B` represents the batch size.

Because molecules have different numbers of atoms, padding is used to create fixed-size tensors. An atom mask is then applied so that padded positions do not incorrectly affect the training loss.

## Model Architecture

The core of the project is a **Graph Variational Autoencoder**.

The encoder receives the molecular graph and learns a probabilistic latent representation:

```text
Molecular Graph
      │
      ▼
GNN Encoder
      │
      ▼
Dense Representation
      │
   ┌──┴──┐
   ▼     ▼
z_mean z_logvar
   │
   ▼
Sampling
   │
   ▼
    z
```

The latent vector is then passed to the decoder:

```text
             z
             │
             ▼
          Decoder
       ┌─────┼─────┐
       ▼     ▼     ▼
     Nodes  Edges  Global
       │     │      │
       └─────┼──────┘
             ▼
      Molecular Graph
```

## Loss Function

The training objective combines several components because reconstructing a molecule involves more than predicting a single output.

The total loss is composed of:

```text
Total Loss
    │
    ├── Node Reconstruction Loss
    ├── Edge Reconstruction Loss
    ├── Adjacency Loss
    ├── Global Feature Loss
    └── β × KL Divergence
```

In simplified form:

```text
L = Lnode + Ledge + Ladj + Lglobal + βLKL
```
<p align="center">
  <img src="assets\loss\4.PNG" width="900">
</p>

The reconstruction terms encourage the decoder to reproduce the input molecular graph, while the KL divergence regularizes the latent space.

## Current Limitations

The current implementation is primarily focused on learning and generating molecular graph structures.

Some limitations remain:

* Generated bond distributions are not yet fully aligned with the training distribution.
* The model can favor single-bond predictions.
* Chemical validity and diversity can still be improved.
* The current project does not include reinforcement learning.
* Property optimization is not part of the current training pipeline.

These limitations are useful directions for future experimentation rather than being treated as solved problems.
